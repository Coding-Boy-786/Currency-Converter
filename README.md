# CurrencyX — Live Currency Converter

A modern and responsive currency converter web app built with HTML, CSS, and JavaScript. Convert currencies instantly with real-time exchange rates, quick amount shortcuts, live rate updates, and a clean UI.

---

## ✨ Features

* 🌍 Convert 150+ currencies instantly
* ⚡ Real-time exchange rates
* 📜 Conversion history section
* 📈 Live exchange rate updates
* 🔄 Swap currencies button
* 🌙 Light/Dark mode toggle
* 📱 Fully responsive design
* 🎯 Quick amount shortcuts
* 📋 Copy converted value

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
